# Population by municipality of Mexico, ITER 2020

Population of each municipality of Mexico by sex and age group, from the
territorial indicators (ITER, \*Integración Territorial\*) of the 2020
Population and Housing Census of INEGI. Useful as denominators to
calculate incidence rates.

## Usage

``` r
pop2020
```

## Format

A tibble with 2,469 rows (municipalities) and 44 columns. All population
columns are numeric:

- CVEGEO:

  five-digit municipality code of INEGI (state + municipality).

- pobtot:

  total population.

  female population.
